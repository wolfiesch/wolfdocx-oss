# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:
https://github.com/wolfiesch/wolfdocx-oss/security/advisories/new

Do not open a public issue for a suspected vulnerability. Include the wolfdocx
version, the Python version, a description of the impact, and a minimal `.docx` or
script that reproduces the problem when you can share one safely.

You can expect an acknowledgement within a few business days. Fixes are released as
patch versions and disclosed through a published advisory once a fixed release is
available.
